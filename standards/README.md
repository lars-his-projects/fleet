# Standards of the fleet

The rules that each project of the fleet follows. The owner approved them on 2026-11-13
(`steering/project/DECISIONS.md`). The owner edits them at any time: the agents follow the version on `main`.

| File | What it rules |
|---|---|
| `PRINCIPLES.md` | What the owner prefers when two good options compete (S1 to S10) |
| `HUMAN.md` | When an agent asks a person, how it asks, and the budget of the owner's attention |
| `DESIGN.md` | How an agent judges a look with no person |
| `RESOURCES.md` | What the agents can use, and how they ask for more |

## Status

The projects do not load this folder yet. Each project still has its own copy of the system principles
(`steering/system/PRINCIPLES.md`), and the three copies differ. The sync of the agent system (roadmap `system:source`)
replaces the copies with this folder.

Until then:
- A session that works in the hub follows this folder.
- A run in a project follows the copy of the project. When the two differ, this folder shows the direction, and the
  difference is a ticket for the sync.

Some rules name a tool that does not exist yet. Each of these rules says so and names its roadmap feature.
