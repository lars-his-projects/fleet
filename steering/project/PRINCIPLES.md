# Principles: the hub

The hub has no principles of its own. Its direction is `standards/PRINCIPLES.md` (S1 to S10): the same file that
rules the agent system of each project.

A run adds a principle here only when a decision of the owner is about the hub and about no project
(`DECISIONS.md` is the log). Give such a principle a number H1, H2, ... so that it cannot mix with S1 to S10 or with
the P numbers of a project.
