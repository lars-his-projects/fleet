# Decisions: the agent system

The log of the owner's decisions about the agent system: one line per decision, the newest at the end.
`standards/PRINCIPLES.md` holds the principles. Runs only add lines here (`merge=union` in `.gitattributes`).

Columns: date · ticket · decision · recommendation (`taken`, `changed`: the owner combined or changed it, `other`:
the owner chose another option, `-`: no recommendation) · principle (`S<n>`, or `new` when no principle predicts it).
