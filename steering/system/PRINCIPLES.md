# Principles: the agent system

The principles of the agent system for this repository are in `standards/PRINCIPLES.md` (S1 to S10). They are the same
for all projects of the fleet. Do not copy them here.

Agents: before you recommend an option, compare it with `standards/PRINCIPLES.md` and name the principle ("follows S3").
The owner changes a principle only with a decision (`steering/system/DECISIONS.md`).
